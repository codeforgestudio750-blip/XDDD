Features

Todo lo que necesitas,
en una sola app

17 paginas de herramientas para gestionar tus servidores Minecraft como un profesional.

Consola en Tiempo Real

Terminal con colores ANSI, filtros por nivel, comandos RCON y chat integrado. Batch rendering para 60fps.

Backups Automaticos

Crea, restaura y descarga backups como .zip. Programa tareas automaticas cada N minutos.

Tienda Integrada

50 plugins y 50 modpacks populares descargables directamente desde Modrinth con un clic.

Gestion de Jugadores

Ve jugadores online con skins, gestiona whitelist, ops y bans. Soporta Vanilla, BungeeCord y Velocity.

Editor de Archivos

Navegador de archivos con syntax highlighting para YAML, JSON, .properties, TOML e INI.

Bases de Datos

Explora bases de datos SQLite del servidor, exporta/importa .sql, crea y elimina DBs.

Monitoreo en Vivo

Graficas de CPU, RAM y red en tiempo real. Metricas de almacenamiento y uptime del servidor.

Multi-Version

Descarga e instala diferentes versiones de Paper, Forge y Bedrock. Game swap y server importer incluidos.

Licencia Segura

Sistema de licencias offline con hardware-lock. Activate una vez, usa para siempre en tu PC.

FAQ

Preguntas frecuentes

Que es Joincarp?

Joincarp es una aplicacion de escritorio para Windows que te permite gestionar servidores Minecraft Java y Bedrock. Incluye consola, backups, tienda de plugins, gestion de jugadores y 14 herramientas mas.

Como funciona la licencia?

Al comprar recibes un codigo de 16 digitos (XXXX-XXXX-XXXX-XXXX). Lo ingresas en la app y se vincula a tu PC. Es un pago unico de $15 USD via PayPal (djviccesa@icloud.com), sin renovaciones ni suscripciones. Escríbenos por WhatsApp al +51 948 935 232 para coordinar el pago.

Puedo usar la licencia en otra PC?

La licencia esta vinculada a una sola PC (hardware-lock). Si necesitas cambiar de computadora, puedes desactivar la licencia desde Settings y activarla en la nueva.

Funciona con Paper, Spigot, Forge?

Si. Joincarp soporta cualquier servidor basado en Java (Paper, Spigot, Purpur, Forge, Fabric) y tambien Bedrock. Detecta automaticamente el tipo de servidor.

Necesito instalar algo?

No. Joincarp es portable — copias la carpeta dist/ y ejecutas. Tambien hay un instalador NSIS opcional si prefieres tener acceso desde el Menu Inicio.

Que tecnologia usa?

Desarrollado en C++20 con Qt6, usa SQLite para datos, la API de Modrinth para la tienda, y RCON para comandos remotos. Optimizado para Windows 10/11 de 64 bits.
